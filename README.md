# TillFlow

Production-grade multi-tenant POS with M-Pesa payments, built on AWS ECS with Terraform, GitHub Actions, and CodePipeline.

## Repository Structure

- `services/` — application services
- `infra/` — Terraform infrastructure
- `.github/workflows/` — GitHub Actions
- `docs/` — architecture, ADRs, SLOs and runbooks
- `evidence/` — capstone evidence
- `CODEOWNERS` — ownership mapping

## Environment

Daraja Sandbox only. No real money or customer data.
